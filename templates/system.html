健康检查

  • Python 版本 -- 运行环境
  • MySQL 行情库 -- 读根目录 .env / vendor/db_env 连 trade_stock_daily
  • 日 K 抽检 -- 茅台近月日线是否可取
  • DASHSCOPE_API_KEY -- Charles / 团队 LLM
  • 券商桥 -- 默认 file_bridge 账户快照；或 xtquant + QMT_PATH
  • Kris / 策略注册表 / DQN 模型 -- 风控与研究策略是否就绪
  • live_state.json / 晨报 -- 运行态与历史产出

定时任务

scheduler.py 默认 4 个时点 (周一到周五):

  • 07:40 数据增量（vendor/market_data_prep 下的 run_daily.py）
  • 08:30 晨会简报（run_morning_task.py，含回测匹配写入监控池）
  • 09:30 开盘启动 dry-run 主循环
  • 14:55 收盘前 5 分钟停主循环

实现见 scheduler.py（APScheduler + cron）。 跟 web 分进程跑: python scheduler.py。 Windows schtasks: AI_quant_CASEA_daily / AI_quant_morning_brief。

健康检查
定时任务
scheduler.py 默认 4 个时点 (周一到周五)
时间动作说明
07:40数据增量 按 vendor/market_data_prep（或 CASE_A_BOARD_DATA_PREP_DIR）调用 run_daily.py 拉 K 线 + 板块指数
08:30晨会简报 跑 run_morning_task.py: 多因子选股 + 回测匹配策略写入监控池
09:30启动主循环 开盘启动 dry-run 模拟盘 (每分钟巡检一次)
14:55停止主循环 收盘前 5 分钟停, 避免空转
启动方法 (与 web 工作台分两个进程, 互不影响):
cd AIQuant_OpsDesk_DEV
python scheduler.py
单文件 APScheduler，周一到周五自动触发，Ctrl+C 退出；想立刻验证可加 --simulate。 Windows schtasks: AIQuant_OpsDesk_PROD_DailyData(07:40)、AIQuant_OpsDesk_PROD_MorningBrief(08:30)。
